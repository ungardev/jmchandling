# i18n — JMC Handling

Sitio bilingüe. **Español es el idioma principal** (por defecto, `/es/`).
Inglés es versión secundaria y **nativa**, no una traducción literal.

## Archivos

- `src/i18n/es.json` — español (PRIMARIO). Todos los namespaces.
- `src/i18n/en.json` — inglés. **Árbol de claves idéntico**, siempre.

## Regla de oro

> Nunca se añade, mueve ni elimina una clave en un solo diccionario.
> Los dos archivos deben tener exactamente el mismo árbol.

`npm run i18n:check` valida esto, valida que cada `t('...')` exista en ambos
diccionarios y valida las `altKey` del mapa de medios. **Falla el build si algo no cuadra.**

## Uso en componentes

```astro
---
import type { Locale } from '../../i18n/utils';
import { useTranslations } from '../../i18n/utils';

export interface Props {
  locale: Locale;
}

const { locale } = Astro.props;
const t = useTranslations(locale);
---

<h2>{t('home.equipmentHeading')}</h2>
```

- **Ningún literal de español o inglés en el marcado.** Ni en `alt`, ni en
  `aria-label`, ni en `title`, ni en `placeholder`, ni en `content`.
- Los datos que apuntan a claves indirectas usan el patrón `titleKey` /
  `descriptionKey` / `mediaAltKey` (ver `src/data/siteContent.ts`) y se resuelven
  con `t(family.titleKey)`.

## Nombrado de claves

- Dot-notation en minúsculas: `services.families.rampTitle`, `awb.track`, `nav.home`.
- Prefijo por namespace: `nav`, `utilityBar`, `hero`, `services`, `allies`, `about`,
  `equipment`, `safety`, `quote`, `contact`, `footer`, `form`, `common`, `meta`, `home`,
  `media`.
- `media.alt.*` — textos alternativos de todas las imágenes.
- Si añades una sección nueva, añade también sus claves `meta.*`.

## Redactar el inglés

- Inglés de aviación natural: *ramp*, *turnaround*, *apron*, *ground support equipment*,
  *baggage cart*, *belt loader*, *ground power unit*.
- No traduzcas literalmente el español: "Plataforma y GSE" → **"Aircraft support equipment"**
  o "Ramp and GSE", no "Platform and GSE".
- "Mantenimiento GSE" → "GSE maintenance". "Cuidado de aeronaves" → "Aircraft care".
- Tono: precisión de ingeniería, sin superlativos.

## Redactar el español

- Español venezolano profesional. "Mantenimiento", no "Manteniminto".
- Sustantivos de la industria sin anglicismos innecesarios, pero acepta
  *turnaround*, *ramp*, *handling* — son jerga del sector.
- Terminología del negocio: `handling`, `FBO`, `OBF`, `GSE`, `CESEA`, `RAV 111`, `INAC`.
- Números y datos verificados: 2012, 2015, +30 años, 05:00–22:00 VET.

## Anclas de sección

Los `id` de sección son **en inglés y estables en ambos idiomas**:
`#services`, `#equipment`, `#allies`, `#safety`.
Dentro de cada sección se conserva un alias legacy en español
(`<span id="capacidades" class="sr-only" aria-hidden="true"></span>`).
**No elimines los alias legacy**: hay enlaces externos que los usan.

`#about` y `#empresa` ya no son secciones de la home (el bloque corporativo
está en `/es/sobre-jmc` y `/en/about-jmc`), pero se conservan como spans
ocultos en la home para que los deep links antiguos sigan resolviendo.
